# Super-Agentes — Da IA que responde à IA que trabalha

Curso INEMA.CLUB PRO (formato v5, público 40+ não-programador) sobre delegar responsabilidades reais a agentes de IA: o mesmo agente cresce aula a aula, de um pedido solto a uma equipe de agentes com um humano decidindo no fim.

- `landing.html` — página de entrada
- `curso.html` — trilha única, 8 aulas (página única, roteamento por hash)
- `assets/` — motor `curso.js` + `aula.css` (formato-curso-v5)
- `capa/capa.png` — capa oficial 1280×720

Publicado em https://inematds.github.io/agi-pratica/
